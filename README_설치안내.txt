SINNER HOST CLUB 가상 투어 - 웹사이트 시범 완성본

[실행]
1. ZIP 압축을 풉니다.
2. 폴더 안에서 터미널/명령 프롬프트를 열고 python -m http.server 8000 을 실행합니다.
3. 브라우저에서 http://localhost:8000 으로 접속합니다.
(또는 전체 폴더를 Netlify Drop에 올려 배포할 수 있습니다.)

[온라인 게시]
1. https://app.netlify.com/drop 방문 및 로그인
2. SINNER_HOST_CLUB_WEB 폴더 전체를 끌어 놓기
3. 생성된 사이트 주소 확인. 재배포는 수정한 폴더를 다시 업로드.

[포함 이미지]
scenes.json 파일에 모든 장면의 id, floor, group, label, image 경로가 있습니다.
기존 1F, 2F, 3F, B1 및 확인 가능한 4F 21장을 포함합니다.
4F의 이전 집계 22장 중 1장은 현재 검증된 원본 모음에서 찾지 못했으므로 포함했다고 주장하지 않습니다.
5F~RF는 아직 미제작이므로 비활성화됩니다.

[이미지 추가]
assets/ 아래에 새 이미지(.webp, .png, .jpg)를 넣고 scenes.json에 같은 형식으로 항목을 추가합니다.
기존 id와 next/prev는 편의 필드이며 추가 시 같은 그룹의 이전/다음 장면 관계를 갱신해야 합니다.
장면별 물리적 문 위치가 확인되지 않아 '공간 이동'은 현재 같은 층의 다른 그룹으로 이동하는 임시 기능입니다.

[사운드]
배경음1.mp3를 background.mp3로 복사했습니다. 입장 버튼 클릭 후 재생하며 볼륨과 음소거를 조절합니다.
엘리베이터 버튼/도착은 브라우저 합성 비프음으로 구현했습니다. 실제 문/모터 효과음 파일은 아직 없습니다.

[캐릭터]
제공된 안내 직원 PNG를 사용한 간단한 대화 UI가 포함됩니다. 인물별 스토리와 선택형 대화는 추후 확장 영역입니다.

[유의]
현재는 사진 기반 2.5D 투어 시범 사이트입니다. 360도 파노라마나 물리적으로 정확한 3D 동선이 아닙니다.
이미지의 상업적 이용 권리 및 음원 사용 권한은 게시 전 확인하세요.
